# movies-powerbi-dashboard
Movies Analysis Dashboard — Power BI
A Power BI dashboard I built to explore movie performance from different business and industry angles.

The dashboard brings together movie information and financial data to look at revenue, budget, profit, movie volume, industries, studios, release trends, and IMDb ratings in one place.

What the dashboard covers
Total Revenue
Total Budget
Total Profit
Total Movies
Profit by Movie
Revenue by Industry
Movie distribution by Studio
Movies released by Year
Budget vs Revenue analysis
IMDb Rating filtering
Release Year filtering
Dashboard

The report includes interactive filters for:
Release Year
IMDb Rating
The visuals are connected, so selecting a year or rating range updates the analysis across the dashboard.

Dashboard Questions
Some of the questions explored in the report:
Which movies generate the highest profit?
How does revenue vary across industries?
Which studios have the largest number of movies?
